Welcome to Levtus! A lightweight, high-performance HTTP/1.1 engine for Java 25. Built from the ground up with zero external dependencies, leveraging Virtual Threads for massive scalability and modern TLS for native security.

## 🚧 **IMPORTANT - Construction Zone: Pre-v1.0.0** 

Just keep in mind that Levtus hasn't received any LTS support, because it is still in its pre-release version (< v1.0.0)

## When you'll want to use Levtus

- Personal project
- Testing out alternatives to JVM backend framework
- Contributing to Levtus 🐧

## When you won't want to use Levtus

- Production. Levtus hasn't received any LTS, and API will break constantly.
