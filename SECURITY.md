# Security Policy

## Supported Versions

As Levtus is currently in early development (pre-v1.0.0), we follow a rapid iteration model.

| Version | Supported          |
| ------- | ------------------ |
| < 1.0.0 | :white_check_mark: |
| None    | :x:                |

### Pre-v1.0.0 Policy
Levtus is currently in version **0.x.x**. During this phase:
- **No Long-Term Support (LTS):** We do not provide long-term support for specific minor or patch versions.
- **Breaking Changes:** Stability is not guaranteed. Breaking changes will occur frequently as we prioritize **Developer Experience (DX)** and **Performance**.
- **Security Updates:** Security fixes will be applied to the latest available version only. Users are encouraged to stay on the most recent release.

## Reporting a Vulnerability

We take the security of Levtus seriously. If you find a security vulnerability, please do not report it through public issues.

Instead, please report it by:
1. Opening a draft Security Advisory on GitHub (if available).
2. Contacting the maintainers directly through the contact information provided in the [CONTRIBUTING.md](CONTRIBUTING.md) or the repository owner's profile.

We will acknowledge your report within 48 hours and provide a timeline for a fix if the vulnerability is confirmed.
